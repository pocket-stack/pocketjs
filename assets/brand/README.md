# PocketJS Brand Avatars

White-background 1024x1024 avatar exports for profile canvases that explicitly
require white. They are not the product app icon or favicon: those use the
metal mark on `#0a0a0c` so the mark remains legible and consistent.

- `pocketjs-avatar-white-polished.png` is the default white-canvas export.
- `pocketjs-avatar-white-plate.png` keeps the mark extra safe under circular crops.
- `pocketjs-avatar-white-minimal.png` has the strongest small-size contrast.

The matching `.svg` files are the editable sources for each PNG.

The compact black-backed mark lives in `site/assets/favicon.svg`; generated
platform artwork such as the Vita and original-iPhone icons uses the same
black-backed treatment.
