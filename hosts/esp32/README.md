# Symbian Pocket — ESP32-WROVER-B host

Symbian Pocket is a serial-flashed PocketJS firmware for the 学而思“可多”
ESP32 handheld. The application is authored in TSX, evaluated by the complete
QuickJS engine on the ESP32, laid out and rasterized by PocketJS Core, and sent
to the 160×128 ST7735 display as RGB565 frames.

## Runtime architecture

```text
apps/symbian-pocket/*.tsx
        │ bun tools/build.ts
        ▼
QuickJS QBC + PocketJS PAK ─► QuickJS ──► PocketJS Core ──► RGB565 framebuffer
                                                          └─► ST7735, rotation 3
device.ts commands ────────► ESP32 host queues ─────────────► radio / SD / I²C / GPIO
```

This is not a native mock of the UI. `pocketjs_runtime_init()` creates a real
QuickJS runtime, loads the complete guest bytecode generated by the matching
host `qjsc`, feeds the generated PAK to PocketJS Core, and advances the guest
at a fixed 60 Hz cadence. QuickJS allocations use aligned PSRAM, and its device
C build enables the ESP32 PSRAM cache-erratum workaround.

The 4 MiB flash uses `symbian_pocket.csv`: one `0x3E0000` factory application
partition plus NVS and coredump storage. No OTA slot or OTA code is included;
upgrades and restoration use the serial bridge on COM13.

## User controls

| Input | Normal behavior |
|---|---|
| Up / Down / Left / Right | Move focus, lists, keyboard cursor, or Snake |
| A | Confirm / open / type selected keyboard key |
| B | Back; delete one character while editing |
| Hold B | Return to the home screen |
| Hold A | Open quick actions; in Hardware, unlock outputs for 30 seconds |

Wi-Fi credentials are stored in NVS only after a successful connection and an
explicit **Yes** on the save screen.

## Included applications

- Contacts, Messages, Calendar, Alarms, Notes, Calculator
- Files, Gallery, Tones, Snake
- Connectivity: Wi-Fi scan/connect plus BLE and Bluetooth Classic discovery
- Sensors: light and NTC temperature; IMU is shown as not fitted when absent
- Hardware: controller LEDs, buzzer, expansion GPIO, and guarded motor pulses
- Settings: Chinese/English, key tones, device information, and defaults

File writes are restricted to `/SymbianPocket` on the microSD card. Existing
content elsewhere on the card is left unchanged.

## Verified board profile

| Function | Connection |
|---|---|
| TFT | SCK 18, MOSI 23, CS 5, DC 4; software reset; 60 MHz |
| microSD | SCK 18, MISO 19, MOSI 23, CS 22 |
| Buttons | Up 2, Down 13, Left 27, Right 35, A 34, B 12 |
| Buzzer | GPIO14 |
| Light / NTC | GPIO36 / GPIO39 |
| I²C | SDA 21, SCL 15 |
| Controller | `0x40`; LEDs `0xA0/0xA1`; motors `0x0E/0x06` |
| Expansion | GPIO33, GPIO32, GPIO26, GPIO25 |

The hardware probe found ESP32-D0WD revision 1, 4 MiB flash, approximately
4 MiB usable PSRAM, controller `0x40`, and no response from an IMU at `0x68`.

## Output safety

- Every output is driven off during boot.
- Motor control starts locked.
- Holding A in Hardware grants a 30-second output lease.
- Every motor pulse has a maximum two-second deadman deadline.
- Returning home or choosing “All outputs off” stops both motors and clears
  controller LEDs, buzzer, and expansion outputs.
- Hardware diagnostics never actuate a motor automatically.

## Build, flash, and validate

Requirements: Bun, the Espressif Rust toolchain (`cargo +esp`), PlatformIO,
Espressif's `xtensa-esp-elf` GCC 13.2 toolchain, and Python with `fontTools`
and `pyserial`. `prebuild.py` discovers the standard Espressif installation
under `%USERPROFILE%\.espressif\tools`.

```powershell
cd D:\ESP32\XuErSi\pocketjs_frontend_symbian
& "$env:USERPROFILE\.platformio\penv\Scripts\pio.exe" `
  run -d hosts\esp32 -e symbian_pocket

.\hosts\esp32\scripts\flash.ps1 -Port COM13
python .\hosts\esp32\scripts\package.py
```

`validate_firmware.py` requires two five-second status windows and verifies the
real QuickJS/PocketJS boot receipt, 160×128 rotation-3 profile, detected PSRAM,
controller `0x40`, locked outputs, memory ceiling, and at least 50 fixed-step
frames per second.

## Serial receipts

- `SP_HARDWARE`: chip, revision, flash, PSRAM
- `SP_INVENTORY`: controller, IMU, SD, buttons, safe output state
- `SP_BOOT`: runtime-ready state and actual QuickJS/PocketJS flags
- `SP_STATUS`: cadence, rendering, heap, radio, storage, and safety state
- Send `S` for an immediate console snapshot.
- Send `X` to force all outputs off.
